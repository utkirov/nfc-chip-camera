# Feromon Camera

Сайт для продажи NFC-меток («феромонов») для фотоаппаратов. Касание смартфоном →
уведомление **«Оригинал» / Feromon Verified** → цифровая визитка фотографа
(3 фото портфолио, ссылки, контакты).

## Страницы

| Файл | Назначение |
|---|---|
| `index.html` | Лендинг: hero с анимацией «касание → Оригинал → визитка», 3 шага, возможности и параметры чипа, 10 дизайнов (топ-5 с меткой «ХИТ»), сетка скидок + калькулятор, FAQ, CTA |
| `order.html` | Конструктор заказа: 1–10 камер, дизайн на каждую, 3 фото на каждую, профиль NFC (новый / существующая ссылка / как у камеры 1), установка, контакты, живая сводка цены |
| `profile.html` | Демо визитки, которая открывается при касании: экран проверки → «Оригинал», портфолио, кнопки, «Сохранить контакт» (vCard) |

```
assets/
  css/styles.css        — собственные стили (анимации, мокап телефона, формы)
  css/tailwind.src.css  — вход Tailwind
  css/tailwind.css      — собранный Tailwind (коммитится, CDN не нужен)
  js/config.js          — ЦЕНЫ, скидки, дизайны + общий расчёт (FeromonPricing)
  js/landing.js         — лендинг: дизайны, скидки, калькулятор
  js/order.js           — конструктор заказа
```

## Запуск

```bash
npm install
npm run build:css   # после изменения классов в HTML/JS
npm run serve       # http://localhost:8080
```

Сайт статический, его можно выложить на Netlify, Vercel, GitHub Pages или любой хостинг.

## Цены

Всё настраивается в `assets/js/config.js`. Скидка по количеству применяется **ко всем меткам в заказе**
(понятнее клиенту, чем ступенчатая скидка):

| Тариф | Кол-во | Скидка | За шт (при базе 150 000) |
|---|---|---|---|
| Старт | 1 | — | 150 000 |
| Дуо | 2–3 | −10% | 135 000 |
| Студия | 4–5 | −15% | 127 500 |
| Про | 6–9 | −20% | 120 000 |
| Опт | 10 | −25% | 112 500 |
| Дистрибьюторы | 10+ | по запросу | — |

Установка в корпус — опция за каждую камеру (`installPrice`). Калькулятор показывает
зачёркнутую розничную цену, выгоду в сумах и подсказку «добавьте ещё N шт — скидка вырастет до X%».

> Цифры — плейсхолдеры: подставьте свою себестоимость и маржу.

## Дорожная карта

1. **Бэкенд заказов:** `POST /api/orders` (JSON + фото multipart) → хранилище + уведомление в Telegram-бот менеджеру. Сейчас заказ пишется только в `console` (см. `TODO(backend)` в `order.js`).
2. **Настоящая проверка «Оригинал».** Статическую NDEF-ссылку легко скопировать на любую дешёвую метку, поэтому обычный NTAG213/215 не даёт настоящей проверки подлинности. Рекомендуется **NTAG 424 DNA** с SUN-сообщением (Secure Unique NFC): при каждом касании чип добавляет к URL зашифрованный UID и счётчик с CMAC-подписью (`/c/{id}?picc_data=…&cmac=…`). Сервер проверяет подпись и растущий счётчик, и только тогда показывает «Оригинал». Копия метки проверку не пройдёт.
3. **Личный кабинет:** вход по номеру телефона (SMS/Telegram), редактирование визитки, замена фото, статистика касаний.
4. **Оплата:** Payme / Click / Uzum.
5. **Локализация:** узбекский (латиница) + русский.
6. **Перенос на Next.js**, когда появятся кабинет и SSR визиток. Текущая вёрстка на Tailwind переносится 1:1.
